# 기술적인 내용을 다루는 블로그 입니다.
정적 사이트로 배포하고 있습니다.

[블로그 구경 가기](https://thxwelchs.github.io)

### 사용된 기술
- [Astro](https://astro.build/)
- Markdown (글은 `src/posts/*.md`)
- Shiki (코드 하이라이트)

### 로컬 실행

```bash
npm install
npx astro dev      # http://localhost:4321
npx astro build    # 정적 산출물 → dist/
```

Node 22 이상이 필요합니다.
